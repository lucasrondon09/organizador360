# 1. Introdução

## 1.1 Objetivo

Este documento descreve os requisitos do produto Organizador360, definindo sua visão funcional, usuários, funcionalidades, jornadas e critérios de sucesso.

Ele serve como referência para:

- desenvolvimento;
- design;
- testes;
- priorização;
- evolução do produto.

---

# 2. Visão do Produto

O Organizador360 é uma plataforma digital que permite ao usuário centralizar informações importantes da sua vida pessoal.

Através de módulos independentes, o usuário poderá controlar:

- veículos;
- documentos;
- contas;
- vencimentos;
- garantias;
- patrimônio;
- compromissos.

O sistema funcionará como um assistente pessoal de organização.

---

# 3. Proposta de Valor

## Problema

As pessoas possuem diversas informações importantes espalhadas em:

- papéis;
- aplicativos;
- planilhas;
- e-mails;
- mensagens;
- memória.

Isso gera:

- esquecimentos;
- multas;
- perda de garantias;
- gastos desnecessários;
- falta de histórico.

---

## Solução

Criar uma plataforma única que:

- armazena informações importantes;
- alerta antes dos vencimentos;
- mantém histórico;
- organiza documentos;
- facilita decisões.

---

# 4. Objetivos do Produto

- Reduzir esquecimentos.

# 14. Critérios de Aceitação do MVP

O MVP será considerado pronto quando:

- usuário consegue criar conta;
- usuário consegue cadastrar veículo;
- usuário consegue registrar manutenção;
- usuário recebe alerta;
- usuário consegue consultar histórico;
- usuário consegue visualizar dashboard.

---

# 15. Fora do Escopo Inicial

Não fazem parte do MVP:

- inteligência artificial avançada;
- marketplace;
- integração bancária;
- compartilhamento familiar;
- automações complexas.

Esses recursos serão avaliados futuramente.

# 17. Princípio de Priorização

Toda funcionalidade deve responder:

1. Resolve um problema real?
2. Será utilizada frequentemente?
3. Aumenta retenção?
4. Pode gerar receita?

Caso contrário, deve ser priorizada posteriormente.
